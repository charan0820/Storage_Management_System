2. Make the cardboard shelf

Aim for 30 cm clear depth, two ~12 cm wide rows, and walls 12–15 cm high. Start with a ~32 × 27 cm base; adjust for cardboard thickness. Mount each sensor at the rear, 5–6 cm above the base, facing the upright flat follower behind its products.

Slide the follower forward against the remaining products after each removal. Full distance is approximately 5 cm; empty is approximately 30 cm. The follower gives a consistent reflecting surface. Bench-test the small target: loose products alone can give unreliable echoes.

Both VCC pins connect to regulated 5 V and both GND pins to common ground. Confirm your board's 5 V/VIN pin exposes USB 5 V before using it. Do not feed 5 V into 3V3 or tie independent 5 V supplies together.

Never connect a 5 V Echo directly to the ESP32. Check approximately 3.3 V at each divider junction and stay within the ESP32 electrical limits. Use a level shifter if needed. Verify your sensor accepts 3.3 V TRIG; otherwise add a suitable 3.3 V-to-5 V trigger buffer.

4. Bring the application online

  1. Unplug USB, assemble and inspect the wiring, then reconnect power.
  2. From the repository root, install and start:
    python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-device.txt
.venv\Scripts\python.exe -m backend.app
  3. Open the dashboard. Test each row using demo calibration and simulated readings. Stop simulation before physical telemetry.
  4. Connect ESP32 and laptop to the same 2.4 GHz Wi-Fi. Use ipconfig to find the laptop IPv4. Allow private-network inbound TCP 5000 if Windows prompts.
  5. Open firmware/esp32 in PlatformIO. Copy secrets.example.h to secrets.h. Fill in Wi-Fi credentials and BACKEND_URL = "http://LAPTOP_IPV4:5000/api/readings". Set the API key only if enabled on the backend.
  6. Build and upload to the classic ESP32 Dev Module; open Serial Monitor at 115200 baud. Verify sensor → row → tag mappings and HTTP 201 responses. If upload stalls, hold BOOT while connection starts.
  7. Assign product tags and names using each row's Assign / calibrate button. Measure actual full and empty sensor-to-follower distances; choose Measured on physical shelf. Assignments refresh on the board within about 10 seconds.

5. Verify your final demonstration

Test full, half-full, low and empty on each row independently. Wait up to five samples for filtering to settle. Test no echo (sensor fault), then unplug USB and wait 60 seconds (offline). Check alerts clear after fresh stock recovery and settings survive a server restart.

Printed tags are manually assigned, or typed by a USB barcode scanner connected to the laptop. No RFID reader is included. Ultrasonic sensors measure distance and cannot identify products or count arbitrary items. Displayed fill is an estimate.

Electrical and timing references: HC-SR04 datasheet and ESP32 datasheet. Physical accuracy requires validation on your assembled rig.
